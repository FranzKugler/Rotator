AG2998 Rotator

Flash a rotator, from the browser

A blank Seeed XIAO ESP32-S3 (16 MB flash) is ready in about a minute — no ESP-IDF toolchain, no dev container, nothing to install. This page writes the whole flash: bootloader, partition table, firmware and browser interface, in one go.

Before you start

  • Chrome, Edge or Opera on a computer
  • A USB-C cable that carries data
  • A Seeed XIAO ESP32-S3 (16 MB flash)

Safari and Firefox cannot do this — they have no Web Serial API. On a phone or tablet there is no port to connect to at all.

This browser cannot flash a device — open this page in Chrome, Edge or Opera on a desktop instead. Web Serial needs a secure connection. This page should already be HTTPS — if you are seeing this, something in between is stripping it.

If the browser cannot find the board

The XIAO's own USB port is not a classic USB-serial bridge, so it does not always drop into the bootloader by itself. If "Connect" shows no port, or the install stalls right at the start:

  1. Unplug the USB cable.
  2. Hold the board's BOOT button down.
  3. Plug the cable back in while still holding it, then let go.
  4. Click "Connect and install" again.

After it's flashed

The rotator reboots and, over the same USB-C cable, presents a USB network interface at http://192.168.7.1 — no Wi-Fi is configured yet, so this is the only way in at first. Open that address to see the rotator's own interface; the Wi-Fi tab there can join it to a network, after which it also answers at http://ag2998-rotator.local. Update, Debug and Storage sit behind a password you set once at http://192.168.7.1/#expert.

On every boot the rotator turns to find its mechanical zero against the Hall sensor before it does anything else — keep the optics clear before powering it on.

What exactly does this write?

Five parts, at the offsets a factory-fresh XIAO ESP32-S3 needs: the second-stage bootloader, the partition table, the tiny stub that tells it which app partition to boot first, the firmware itself, and the filesystem image holding the browser interface. The "erase" option this tool offers first clears the whole chip, which is the safe default for a board that has never run this firmware before — and the right choice if the partition table has changed since it last did. Reflashing a rotator that is already running this firmware does not need any of this: use its own Update tab instead, which only ever replaces the two halves that actually changed. Built straight from the latest stable release; see CLAUDE.md for how the firmware itself is put together.
